Adding CSS

  1. Inline CSS

    One of the ways of adding CSS to the webpage is by adding the styles inline directly to a HTML Element. Example:

            <div style="color: white;">
            <!-- Content Goes Here -- >
        </div>

  2. Internal CSS

    One of the ways of adding CSS to the webpage is by adding the Style Element inside the Head Element of the HTML file. Example:

            <!DOCTYPE html>
        <html lang="en">
            
            <head>
                <style>
                    div {
                        color: antiquewhite;
                    }
                </style>
            </head>

            <body> 
                <!-- Body Elements and Contents Go Here -- >
            </body>

        </html>

  3. External CSS

    One other way of adding CSS to the webpage is by linking external stylesheet inside the Head Element of HTML file and write css to that external file. Example

            <!DOCTYPE html>
        <html lang="en">
            
            <head>
                <link rel="stylesheet" type="text/css" href="./style.css">
            </head>

            <body> 
                <!-- Body Elements and Contents Go Here -- >
            </body>

        </html>
